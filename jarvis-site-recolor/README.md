# Перекраска сайта JARVIS — вариант 3 «Роли цветов»

Правка к репозиторию сайта (`-kaper-jarvis-bot`, коммит `4dbfc916`). Меняются только цвета, вёрстка не тронута.

- `col3.patch` — правки двух файлов: `team/site/v3a/assets/col.css` и `team/site/v3a/assets/palettes.js`.
- `before-after-phone.png`, `before-after-desktop.png` — слева как было, справа вариант 3.

Применить в корне репозитория сайта:

```bash
git apply col3.patch
```

После этого вариант включается адресом `?col=3`, выключается `?col=off` — так же, как варианты 1 и 2.

Роли цветов: жёлтый — только кнопки действия; синий — всё, что говорит модель; серый — линия букмекера;
зелёный и красный — только исходы (зашло / не зашло).

## Основной вид (10.11)

`default-colors.patch` — полная правка к ветке сайта `claude/team-dev-site-v3a` (от коммита `5b147f0`):
новые цвета становятся видом по умолчанию, прежний вид — `?col=off`. Заменяет `col3.patch`.

```bash
git apply default-colors.patch
```
